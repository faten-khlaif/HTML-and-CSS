# HTML-and-CSS

## Project Structure Overview

This repository houses two fundamental development checkpoints:

### 1. The Native HTML & CSS Student Portfolio
A complete webpage built around a vibrant neon-synthwave visual language tailored specifically for **Faten Khlaif**. It serves as an implementation canvas for clean core CSS positioning and rendering mechanics, featuring:
* **Fixed Navigation Mechanics:** Sticky header navigation styled with sleek transition hover reactions.
* **Graphic Processing:** Advanced CSS graphic filters, image overlays fading states, and positioning rules managing multi-dimensional elements.
* **Video Layer Rendering:** Native container setups showcasing dynamic video configurations configured with an loop-cycle, automated audio isolation masking, and absolute text masking placement.
* **Structured Grid Assets:** Clean block sizing control via explicit height-by-width layouts alongside completely stylized tracking tables.

### 2. The Bootstrap Responsive Framework Project
An accompanying dashboard interface project leveraging the grid components, pre-compiled utilities, and layout containers of the **Bootstrap Framework**. It highlights:
* Rapid responsive prototype structures using utility-first layout breakpoints.
* Modular flex layouts utilizing library components.
* Consistent presentation layouts across variable screen breakpoints.
